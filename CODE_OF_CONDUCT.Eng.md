# Code of Conduct

One line: **argue hard about the code, never about the person.**

There's exactly one rule here — you're free to take someone's idea apart, but not the person who had it.

## What gets removed, closed, or blocked

- Mocking questions. "You don't know that?" "Beggar", "homework from a 12-year-old" — none of it, whether aimed at a first-timer or a regular.
- Personal attacks, slurs, or using gender / region / education / age / money as ammunition.
- Status theatre: putting someone's approach down to make yours look bigger is more common than arguing from evidence, and it gets you shown the door faster.
- Publishing someone's DMs, email, or anything identifying from their logs, or dragging a private conversation into a public issue.
- Spamming, re-opening the same closed issue repeatedly, derailing pull requests with unrelated arguments.
- Using "freedom" or "the spirit of open source" as grounds to abuse maintainers for not doing work for you.

## What's encouraged

- Saying "I genuinely don't know this" beats bluffing, every time.
- Disagreeing with evidence: logs, reproduction steps, the other person's source — not "I just don't think it works".
- Telling the maintainer they're wrong, product decisions included. This project's own planning doc has been rewritten more than once.
- Bundling a bug report with a minimal reproduction.

## How maintainers handle it

In escalating order: comment removed → issue closed → temporary block → permanent block. No public trial, and no second explanation.

If you think a decision was wrong, take it to the maintainer privately. Don't reopen the fight in an issue.

## Scope

Issues, pull requests, discussions, and anywhere you're acting as part of this project — including saying "I contribute to Nuitka++" somewhere else.

## Reporting

Open an issue prefixed with `[conduct]`, or email the address on the maintainer's profile. What you report and who you are stay private.

---

This follows the broad shape of codes of conduct common across open source, trimmed to the length this project will actually use. It applies to everyone, maintainers included.
